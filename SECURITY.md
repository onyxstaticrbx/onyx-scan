# Security policy

`onyx-scan` is a security tool, so please do not report a vulnerability in a public issue.

Use GitHub's private vulnerability reporting form:

https://github.com/onyxstaticrbx/onyx-scan/security/advisories/new

Please include:

- the package version (`python -m pip show onyx-scan`);
- the rule id, if a finding is involved;
- the smallest reproduction you can share.

Do **not** attach a private place file or account details. A code snippet, the relevant
path and line, and the command you ran are enough to start.

This is a source-available project under FSL-1.1-ALv2; reports about this repository and its
published package are welcome through the private form above.

## Contributions

Issues are welcome. Pull requests are not accepted for now.
